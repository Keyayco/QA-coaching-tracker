About this workspace.

QA Command Centre reads and writes directly to this Google Sheet. There is no separate database — every value shown here is calculated live from the Departments, Agents, Coaching Log, Performance Log, and Dispute Log tabs.

Individual audit records remain the responsibility of each line of business's own operational system (e.g. Zendesk, Talkdesk) — this tool only stores consolidated weekly performance, coaching sessions, and disputes.

Scorecard Templates

Each department can have one or more scorecard templates, versioned over time, each with its own scoring methodology.

Add Scorecard Template

Scoring Type is free text so new methodologies can be added without changing this form — currently recognized values are "Weighted Percentage" and "Critical Failure + Weighted Percentage". Anything else falls back to Weighted Percentage automatically.
